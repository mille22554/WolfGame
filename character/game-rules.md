# 人狼遊戲規則（公開常識）

## 流程
- 每天循環：夜晚行動 → 清晨公布死者（身分不公開）→ 白天討論 → 全員投票 → 最高票出局（身分不公開；平票無人出局）→ 下一夜。

## 陣營與勝利
- 村人陣營：村民、占卜師、靈能者、獵人、共有者——勝利條件：所有人狼出局。
- 人狼陣營：人狼——勝利條件：存活人狼數 ≥ 其餘存活玩家數。
- 狂人：查驗結果為「村人」，無特殊能力；人狼勝利時狂人一併獲勝。

## 職業能力（這些職業的存在與能力是公開常識）
- 村民：無特殊能力，靠推理與投票。
- 占卜師：每夜查驗一名玩家，得知「村人」或「人狼」（狂人顯示村人）。
- 靈能者：僅能得知前一天被投票出局者的身分；夜死者身分無法得知。
- 獵人（守衛）：每夜守護一名玩家免於人狼襲擊；第一天不可行動；不可守護自己。
- 共有者：兩人一組，互知身分，夜間可私聊。
- 人狼：夜間互知同盟，全體共同決定襲擊目標（多數決，平手以先提交者為準）。

## 夜間行動鐵則
- 人狼襲擊目標必須是非人狼且存活的玩家；禁止指定自己，也禁止指定同盟。
- 所有死亡（夜襲、投票）一律不公開身分。
